# Pandas Gordos PRO — Releases

Repositório oficial de distribuição do **Pandas Gordos PRO**.

Este repositório contém somente artefatos públicos de instalação e atualização:

- instaladores do Windows;
- assinaturas do atualizador;
- arquivo `latest.json`;
- checksums SHA-256;
- notas de cada versão.

O código-fonte, as chaves privadas de assinatura e as configurações internas não são publicados aqui.

## Downloads

Use a seção **Releases** para baixar a versão mais recente do aplicativo.

## Segurança

Antes de instalar, confira o checksum publicado junto ao instalador. As atualizações automáticas também são verificadas por assinatura digital pelo aplicativo.

Desenvolvido por **FullSpeedSS**.
